Profile / Settings / Tithes / Visitor

Auth stays as-is. These mockups cover the remaining utility surfaces: account chrome and the two info screens that still feel card-heavy next to Quiet Stream / Soft Continuity.

2 · Quiet Account — Profile identity as a left-aligned editorial header (not a centred poster), then divider rows instead of a ListTile card. Settings drop nested Cards for section labels + segmented controls. Feedback becomes Quiet Stream rows with status chips.

3 · Calm Info — Tithes keeps a Cover Stage image but banks details become copyable quiet rows. Visitor loses the tinted welcome box; service times and events follow the same quiet rhythm as home/calendar.
