Prayer request card — quiet redesign

Same functionality, less stacked chrome: one meta row instead of three chips, body first, a single praise inset (no duplicate label), and a compact praying action. Used everywhere this card appears — community feed and My Prayer Requests.

What changes

  • One meta row — category + optional status. Drop the redundant “Answered Prayer” chip when a praise block exists.
  • Body first — request text is the hero of the card.
  • Quiet byline — name · date on one muted row.
  • Praise once — short “Praise” inset with left accent, not a chip + nested titled box.
  • Compact pray — ♥ Praying · 1 instead of a long ActionChip sentence.
  • Resolve stays available as a quiet secondary action for owners.

Functionality kept

  • Category label
  • Status (when showStatus / My requests)
  • Moderation note
  • Praise report on resolved
  • Pray / un-pray toggle + count
  • Mark as resolved (owner)
  • Read-only count on resolved cards
