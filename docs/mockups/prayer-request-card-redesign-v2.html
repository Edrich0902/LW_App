Prayer card — minimal v2

Stripped further: no chips, no nested panels, no accent bars, no gradients. The prayer text is the card. Everything else is one quiet line of meta, optional praise as plain muted text, and a heart count.

What we removed

  • Category / status chips → folded into one muted meta line
  • Praise box + left bar + PRAISE label → plain muted paragraph
  • “Praying · N” pill → heart + number only
  • Resolved gradient / tinted border → same quiet card as open
  • Mark resolved chip → simple text action

Still supported

  • Category (in meta)
  • Status when useful (pending / rejected / resolved in meta)
  • Moderation note as muted text
  • Praise report as muted text
  • Pray toggle + count
  • Owner “Mark resolved”
